# M10 — MongoDB: plan de implementación

Spec: [m10-mongodb-design](../specs/2026-10-23-m10-mongodb-design.md). Rama `milestone-10-mongodb`, apilada sobre `milestone-8-docker` (PR #10 sin mergear; M9 se canceló). Sin tests automatizados: cada tarea termina con `npm run check`; pruebas manuales en la spec §5 y en `vault/steward/Estado.md`.

Desviaciones deliberadas respecto a la spec:

- **Parser:** se usa `@mongodb-js/shell-bson-parser` directamente (es lo que `mongodb-query-parser` envuelve); el segundo paquete se descartó. Es un parser de sintaxis, no un `eval`.
- **Editor:** `textarea` monoespaciada en lugar de CodeMirror (la alternativa que la spec permitía).
- **Sin 10.4:** shell `mongosh`, GridFS y `currentOp` quedan fuera.
- **Sin "Detect local"** con los containers de Docker.
- `mongo:count` admite `exact` (cuenta de verdad aunque el filtro esté vacío): los borrados/actualizaciones masivos se comprueban contra ese número.
- Importar: el renderer elige el archivo con `mongo:pickFile` y recibe un **token opaco**; `mongo:import` lo resuelve en main. Ninguna ruta llega del renderer.
- Exportar: el diálogo de guardado lo abre main dentro de `mongo:export`.
- Las consultas recientes no se guardan; solo las guardadas por el usuario (`mongo_saved_queries`).

## Tareas

1. **Dependencias** (versión exacta): `mongodb`, `bson`, `@mongodb-js/shell-bson-parser`, `mongodb-connection-string-url`. Sin binarios nativos (los módulos opcionales del driver no se instalan).
2. **Datos**: m017 (`data_connections`, `mongo_saved_queries`, pestaña `mongodb`), `db/data-connection.repo.ts`. `data_connections` es común y la reutilizará Redis.
3. **Compartido**: `schemas/mongodb.ts`; `shared/mongo/shell-format.ts` (EJSON canónico ⇄ sintaxis de shell, puro, usado por el renderer); 33 canales `mongo:*` en `ipc.ts`/handlers/preload; códigos de error `MONGO_*` y `CONNECTION_READ_ONLY`.
4. **Main**:
   - `mongo-uri` (URI desde formulario, host sin credenciales, Atlas), `mongo-errors` (traduce errores del driver con pista de Atlas), `mongo-ejson` (parseo seguro, serialización canónica).
   - `mongo-pool` (un cliente por conexión, perezoso, cierre por inactividad, máx. 6), `mongo-connection.service` (CRUD, secreto en `secret-store`, prueba), `mongo-data.service` (explorar, find, CRUD, masivos con `expectedCount`, soltar, agregación, índices, esquema, validación, guardadas, escrituras auditadas), `mongo-schema`, `mongo-io.service` (import/export JSON, JSON Lines, CSV), `mongo.service` (fachada).
   - `main/index.ts`: secret store compartido con GitHub, diálogos de archivo, cierre en `will-quit`; borrar un proyecto purga clientes y secretos.
5. **UI** `features/mongodb/`: `MongoPanel`, `ConnectionDialog`, `Explorer`, `CollectionView` con `DocumentsView` (List / JSON / Table), `AggregationView`, `SchemaView`, `IndexesView`, `ValidationView`, `DocumentEditor`, `BulkDialog`, `DropDialog`, `ExplainPanel`.
6. **Cierre**: `npm run check`, build, README, CHANGELOG, graphify, vault.
